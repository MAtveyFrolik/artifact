📋 ПОЛНАЯ ИНСТРУКЦИЯ (Шаг за шагом)

ШАГ 1️⃣: Создайте Google Таблицу
1. Откройте sheets.google.com
2. Нажмите "+ Создать" (слева)
3. Выберите "Таблица"
4. Назовите её "Инвентарь" (или любое имя)
5. ✅ Таблица создана!
ШАГ 2️⃣: Добавьте Google Apps Script
1. В Google Таблице нажмите "Расширения" (в меню сверху)
2. Выберите "Apps Script"
3. Откроется новое окно - это редактор скрипта
4. УДАЛИТЕ весь текст который там уже есть (Code.gs)
5. ВСТАВЬТЕ весь код ниже:
const SHEET_NAME = 'Products'; const SUPPLIERS_SHEET = 'Suppliers'; function doPost(e) { try { const data = JSON.parse(e.postData.contents); saveData(data); return ContentService.createTextOutput(JSON.stringify({status: 'ok'})).setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService.createTextOutput(JSON.stringify({status: 'error', msg: err})).setMimeType(ContentService.MimeType.JSON); } } function doGet(e) { if(e.parameter.action === 'test') { return ContentService.createTextOutput(JSON.stringify({status: 'ok'})).setMimeType(ContentService.MimeType.JSON); } } function saveData(data) { const ss = SpreadsheetApp.getActiveSpreadsheet(); const productsSheet = ss.getSheetByName(SHEET_NAME) || ss.insertSheet(SHEET_NAME); const suppliersSheet = ss.getSheetByName(SUPPLIERS_SHEET) || ss.insertSheet(SUPPLIERS_SHEET); productsSheet.clear(); suppliersSheet.clear(); productsSheet.appendRow(['ID', 'Name', 'Photo', 'Competitors', 'Dates']); const products = data.products || []; products.forEach(p => { productsSheet.appendRow([p.id, p.name, p.photo, JSON.stringify(p.competitors), p.dateAdded]); }); suppliersSheet.appendRow(['ID', 'Name', 'Phone', 'Email', 'Website', 'Notes']); const suppliers = data.suppliers || []; suppliers.forEach(s => { suppliersSheet.appendRow([s.id, s.name, s.phone, s.email, s.website, s.notes]); }); }
ШАГ 3️⃣: Разверните скрипт
1. В левом меню нажмите "⚙️ Развернуть"
2. Выберите "Новое развертывание"
3. Нажмите значок шестеренки ⚙️ в "Тип"
4. Выберите "Веб-приложение"
5. Выберите:
  - Выполнять как: Ваш Gmail (например: you@gmail.com)
  - Кто имеет доступ: "Все"
6. Нажмите "Развернуть"
7. Дождитесь сообщение об успехе
ШАГ 4️⃣: Скопируйте URL
1. После развертывания Google покажет окно
2. СКОПИРУЙТЕ ссылку (она начинается с https://script.google.com/...)
3. Нажмите кнопку копирования (или Ctrl+C)
ШАГ 5️⃣: Вставьте URL в приложение
1. Вернитесь в это приложение
2. ВСТАВЬТЕ скопированный URL в поле выше
3. Нажмите "💾 Сохранить"
4. Нажмите "🔗 Проверить подключение"
5. Если всё ок - будет ✅ Подключено!
6. Готово! 🎉
